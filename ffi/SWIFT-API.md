# KhensuCore Swift API (v0.2)

Generated by UniFFI 0.32 from `crates/khensu-ffi`. Build with:

```sh
./scripts/build-xcframework.sh
```

Outputs:

| Path | What |
| --- | --- |
| `target/KhensuCore.xcframework` | Static library `libkhensu_ffi.a` for `ios-arm64`, `ios-arm64-simulator`, `macos-arm64`, each with `KhensuCoreFFI.h` and `module.modulemap` (`module KhensuCoreFFI`) |
| `target/swift/KhensuCore.swift` | The Swift API. Add it to the app target (or a local Swift package named `KhensuCore` that depends on the XCFramework); it does `import KhensuCoreFFI` |

Minimum deployment target is iOS, iPadOS and macOS 26. All objects are `Sendable` and internally locked; calls are synchronous and CPU-bound (ML-KEM, ML-DSA, MLS), so call them off the main actor. Byte strings are `Data`. IDs are lowercase hex `String`s. Times are Unix milliseconds (`UInt64`).

## Errors

Every `throws` function throws `KhensuError`:

```swift
public enum KhensuError: Swift.Error {
    case Invalid(msg: String)   // malformed input, wrong lengths, bad contact card
    case Crypto(msg: String)    // decryption or signature failure, wrong state key
    case Mls(msg: String)
    case Network(msg: String)   // no directory, no gateway, no route
    case NotFound(msg: String)  // unknown conversation
    case State(msg: String)     // state blob or handshake misuse
}
```

## `KhensuClient`

One per device. Holds the identity, MLS groups, outbox, fetch schedule and partial messages.

```swift
public class KhensuClient {
    public convenience init(displayName: String, nowMs: UInt64) throws
    public static func importState(blob: Data, key: Data) throws -> KhensuClient

    public func exportState(key: Data) throws -> Data
    public func identity() -> IdentityInfo

    public func loadDirectory(json: String, gateway: String?) throws
    public func gateway() throws -> GatewayInfo
    public func networkEpoch(nowMs: UInt64) -> UInt64
    public func tickIntervalMs() throws -> UInt64
    public func deliveryId() -> Data

    public func createContactCard(nowMs: UInt64) throws -> String
    public func createGroup(title: String) throws -> String
    public func createDirectConversation(contactCard: String, nowMs: UInt64) throws -> String
    public func addMember(conversationId: String, contactCard: String, nowMs: UInt64) throws
    public func conversations() -> [ConversationInfo]

    public func sendText(conversationId: String, text: String, nowMs: UInt64) throws -> String
    public func encryptMessage(conversationId: String, text: String, nowMs: UInt64) throws -> EncryptedMessage
    public func pendingOutgoing() -> UInt32

    public func tick(nowMs: UInt64) throws -> [OutgoingPacket]
    public func processIncoming(payloadKeyRef: Data, payload: Data, nowMs: UInt64) throws -> [ClientEvent]

    // v0.2: epoch headers, loop probes, store receipts
    public func processControl(message: Data, nowMs: UInt64) throws -> [ClientEvent]
    public func headerRequest() throws -> Data
    public func networkStatus(nowMs: UInt64) -> NetworkStatus
    public func setLoopRate(per100Ticks: UInt32)
    public func setStoreReceipts(on: Bool)
}
```

| Call | Notes |
| --- | --- |
| `init(displayName:nowMs:)` | New identity (ML-DSA-87 identity key, signed inception entry, device 0 credential). Display name is local and goes into contact cards only |
| `exportState(key:)` / `importState(blob:key:)` | Whole client state sealed with a 32-byte key under AES-256-GCM. Keep the key in the Keychain (`kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`, no iCloud sync). Call `loadDirectory` again after import. Export after every call that mutates state you care about (send, tick, processIncoming) or at least on backgrounding |
| `loadDirectory(json:gateway:)` | Contents of `devnet.json` (format below). `gateway` is a node `name`; `nil` takes the first gateway |
| `gateway()` | The entry node to connect to: endpoint plus its link keys |
| `tickIntervalMs()` | `params.tick_ms` (2000 on the devnet) |
| `deliveryId()` | 32 bytes; send it in a subscribe frame right after the link handshake |
| `createContactCard(nowMs:)` | Base64 string (~28 KB): a one-time MLS KeyPackage, an ML-KEM-1024 intro key, display name, signed. Share it out of band (QR, AirDrop, file). Each card works once; make a new one per contact |
| `createDirectConversation(contactCard:nowMs:)` | Returns the conversation ID. Queues the Welcome to the card owner |
| `createGroup(title:)` / `addMember(...)` | Group conversations; `addMember` commits and queues the Welcome plus the commit to existing members |
| `sendText(...)` | Queues; the message leaves over the next ticks in place of cover. Returns the message ID |
| `encryptMessage(...)` | Builds the packets immediately, outside the tick schedule. Tools and tests only |
| `tick(nowMs:)` | Call exactly every `tickIntervalMs()`, whether or not anything is queued. Returns 1 bulk packet (73,736 B) then `small_per_tick - 1` small packets (10,248 B); unused slots are cover. Send every packet on the link with `sealPacket` |
| `processIncoming(...)` | Feed every `LinkFrame.deliver` here. Cover and unknown references return `[]` |
| `processControl(message:nowMs:)` | Feed every assembled `LinkFrame.control` message here. The gateway pushes each new epoch header once the committee has signed it; a header that follows the current one is checked (committee signatures against the current header, lease signatures, rules) and installed at the epoch boundary, giving `.headerAccepted`. A repeated header returns `[]`. A header more than one epoch ahead throws `KhensuError.Network`: send `headerRequest()` and the gateway replies with the chain from your epoch |
| `headerRequest()` | A control message asking the gateway for every header after the one the client holds. Send it with `sealControl` after connecting and whenever `processControl` throws |
| `networkStatus(nowMs:)` | Counters for a network-test screen (below) |
| `setLoopRate(per100Ticks:)` | How many of each 100 ticks carry a loop probe in place of cover: a packet through the gateway and the three mixes back to this client, measured as `.loopReturned`. 0 (default) sends none; a test screen uses 100 |
| `setStoreReceipts(on:)` | Ask each mailbox replica to sign for the items it stores (`.storeReceipt`). Off by default: the receipt costs a bulk-lane reply per fragment |

### Records and events

```swift
public struct IdentityInfo {
    public var address: String          // bech32m, "khensu1…"
    public var addressHex: String
    public var displayName: String
    public var deviceIndex: UInt16
    public var identityPublicKey: Data  // ML-DSA-87, 2592 bytes
}

public struct ConversationInfo {
    public var conversationId: String
    public var title: String            // group title; for 1:1 the other side's display name
    public var direct: Bool
    public var epoch: UInt64            // MLS epoch
    public var active: Bool             // false after removal
    public var members: [MemberInfo]
}

public struct MemberInfo {
    public var address: String
    public var deviceIndex: UInt16
    public var leafIndex: UInt32
    public var isSelf: Bool
}

public struct GatewayInfo {
    public var name: String
    public var nodeId: String           // hex
    public var endpoint: String         // "host:port", UDP
    public var kemPublicKey: Data       // ML-KEM-1024 link key, 1568 bytes
    public var sigPublicKey: Data       // ML-DSA-87, 2592 bytes
}

public struct OutgoingPacket {
    public var firstHop: String         // hex node ID, always the gateway
    public var endpoint: String
    public var bytes: Data              // 10,248 or 73,736 bytes
}

public struct EncryptedMessage {
    public var messageId: String
    public var packets: [OutgoingPacket]
}

public struct NetworkStatus {
    public var network: String          // "devnet"
    public var epoch: UInt64            // from the clock
    public var headerEpoch: UInt64      // epoch of the installed header
    public var nextHeaderEpoch: UInt64? // next header already accepted, waiting for the boundary
    public var nodes: UInt32
    public var committee: UInt32
    public var mailboxReplicas: UInt8
    public var gateway: String
    public var ticks: UInt64
    public var pending: UInt32          // queued outgoing items
    public var loopsSent: UInt64
    public var loopsReturned: UInt64
    public var lastLoopRttMs: UInt64?
    public var headersAccepted: UInt64
    public var storeReceiptsOk: UInt64
    public var storeReceiptsBad: UInt64 // a replica's receipt failed to verify
}

public enum ClientEvent {
    case messageReceived(conversationId: String, messageId: String, senderAddress: String, senderDevice: UInt16, text: String, sentAtMs: UInt64)
    case conversationJoined(conversationId: String, title: String, direct: Bool)
    case membersChanged(conversationId: String)
    case removedFromConversation(conversationId: String)
    case loopReturned(rttMs: UInt64, hops: UInt32)               // a loop probe came back through the mixes
    case headerAccepted(epoch: UInt64, nodes: UInt32, committee: UInt32)
    case storeReceipt(replica: String, epoch: UInt64, valid: Bool) // replica is the node name
}
```

Messages go to every mailbox replica (`mailboxReplicas` of them, chosen per rendezvous from the header), so `encryptMessage` returns `fragments × replicas` packets and the recipient fetches from the replicas in turn.

## Logging

```swift
public enum LogLevel { case trace, debug, info, warn, error }
public protocol LogSink: AnyObject {
    func log(level: LogLevel, target: String, message: String, fields: String)
}
public func setLogSink(sink: LogSink, minLevel: LogLevel) -> Bool
```

`setLogSink` installs the sink for the process once (returns `false` if one is already installed) and routes every core event to it: `target` is the Rust module (`khensu_ffi::core`, `khensu_net::directory`…), `message` the event name (`loop.returned`, `header.accepted`, `receipt.bad`, `directory.rolled`, `fetch.sent`…) and `fields` the structured fields as `key=value` pairs. Call it before creating the client. The call comes on whatever thread produced the event: hop to the main actor before touching UI. Nothing in the fields is secret, but `.debug` and `.trace` name conversations and nodes, so keep `.info` outside test builds.

## Link to the gateway

The app owns the QUIC connection (Network.framework); KhensuCore does the inner post-quantum handshake and frame sealing.

```swift
public func linkExporterLabel() -> Data          // "khensu camouflage v1"
public func linkAcceptLength() -> UInt32          // 4661
public func linkFrameLength(prefix: Data) throws -> UInt32

public class LinkHandshake {
    public convenience init(nodeKemPublicKey: Data, nodeSigPublicKey: Data, tlsExporter: Data, networkEpoch: UInt64) throws
    public func hello() -> Data                   // length-prefixed, write as is
    public func finish(accept: Data) throws -> LinkSession   // accept without its prefix; single use
}

public class LinkSession {
    public func sealPacket(packet: Data) throws -> Data      // length-prefixed
    public func sealSubscribe(deliveryId: Data) throws -> Data
    public func sealPadding(bulk: Bool) throws -> Data
    public func sealControl(message: Data) throws -> [Data]  // one or more frames, write them in order
    public func openFrame(sealed: Data) throws -> LinkFrame  // bytes after the prefix, in stream order
}

public enum LinkFrame {
    case deliver(payloadKeyRef: Data, payload: Data)
    case packet(bytes: Data)
    case subscribe(deliveryId: Data)
    case padding
    case control(message: Data)   // a whole control message: pass it to client.processControl
    case controlPart              // part of a larger control message; the session is still assembling it
}
```

Connection:

1. QUIC (`NWProtocolQUIC.Options(alpn: ["h3"])`) to `gateway().endpoint`. TLS 1.3 with the hybrid group X25519MLKEM768 (the iOS 26 default); nodes refuse other groups. Node certificates are self-signed and ephemeral: accept any certificate in `sec_protocol_options_set_verify_block`, because the node is authenticated by its ML-DSA-87 signature over the TLS exporter in step 4.
2. Once ready, export 64 bytes with `sec_protocol_metadata_create_secret(metadata, label.count, label, 64)` using `linkExporterLabel()` (empty context).
3. Open one bidirectional stream. Create `LinkHandshake(nodeKemPublicKey: gw.kemPublicKey, nodeSigPublicKey: gw.sigPublicKey, tlsExporter: exporter, networkEpoch: client.networkEpoch(nowMs:))` and write `hello()`.
4. Read 4 bytes (big-endian `UInt32`, must equal `linkAcceptLength()`), then that many bytes, and call `finish(accept:)`. Any failure: close and retry later with backoff.
5. Write `sealSubscribe(deliveryId: client.deliveryId())`, then every frame of `sealControl(message: client.headerRequest())` so the gateway sends any headers the client missed while offline.
6. Every `tickIntervalMs()`: `for p in try client.tick(nowMs:) { write(try session.sealPacket(packet: p.bytes)) }`.
7. Read loop: 4-byte prefix, `linkFrameLength(prefix:)` (throws on an impossible size: close the link), read that many bytes, `openFrame(sealed:)`. On `.deliver`, call `client.processIncoming(payloadKeyRef:payload:nowMs:)`; on `.control`, call `client.processControl(message:nowMs:)` (if it throws `.Network`, write `sealControl(message: client.headerRequest())`); handle the events. Ignore `.padding` and `.controlPart`.

Frames are opened strictly in order (counter nonces), so use one read loop per link. The gateway sends a constant number of frames per tick (deliveries or padding); the client's outgoing rate is constant because `tick` always returns the same burst. Reconnecting creates a new `LinkHandshake` and a new subscribe; the `KhensuClient` survives.

Epochs are an hour long. The client needs the header of the current epoch to build packets: it installs the next one by itself at the boundary once `processControl` has accepted it, and a client that has been offline for more than an epoch gets the chain through `headerRequest()`. Until the chain arrives, `tick` throws `KhensuError.Network` ("no mix key for epoch"); keep ticking, the packets resume once the header is installed.

## `devnet.json` (directory v2)

Written by `khensu-devnet/devnet up`; the app can bundle it or load it from a file or URL on the local network. Since v0.2 the directory is the genesis epoch header plus the leases it covers, so `loadDirectory` checks every signature (the founder's cosignature on the genesis header, the committee's, each node's lease) and derives the nodes from the leases.

```json
{
  "version": 2,
  "network": "devnet",
  "genesis_time": 1791504000,
  "epoch_secs": 3600,
  "rules": {
    "version": 1, "chain_id": 1, "committee_size": 6, "threshold": 5, "founder_pk": "<base64>",
    "tick_ms": 2000, "small_per_tick": 4, "downstream_per_tick": 4, "mix_delay_mean_ms": 250,
    "surbs_per_fetch": 4, "link_small_rate_mpps": 20000, "link_bulk_rate_mpps": 2000,
    "node_loops_per_min": 12, "mailbox_replicas": 2, "mix_layers": 3,
    "camouflage_profile": 0, "min_return_permille": 500
  },
  "header": "<base64 EpochHeader>",
  "leases": ["<base64 Lease>", "…"]
}
```

A lease names the node, its roles (`gateway`, `mix`, `mailbox`, `committee`, `relay`), endpoint, ML-DSA-87 key, ML-KEM-1024 link key and one mix key per epoch for the epochs it covers; nodes renew their own leases, and later headers reach the app over the link as `.control` messages. A devnet directory file ages out when its nodes' first leases do (24 epochs by default): if `loadDirectory` or `tick` throws `KhensuError.Network`, regenerate with `./devnet up --fresh`. On the simulator, `127.0.0.1` reaches the Mac; on a device, run the devnet with `--host <mac LAN IP>`.

## Typical flow

```swift
let client = try KhensuClient(displayName: "Alice", nowMs: now)
try client.loadDirectory(json: devnetJson, gateway: nil)
// connect the link (above), start the tick timer
let card = try client.createContactCard(nowMs: now)          // show as QR / share
let chat = try client.createDirectConversation(contactCard: theirCard, nowMs: now)
_ = try client.sendText(conversationId: chat, text: "hi", nowMs: now)
// events arrive from processIncoming: .conversationJoined, .messageReceived …
let blob = try client.exportState(key: stateKey)              // persist
```

Delivery takes several ticks: messages wait for a slot, cross three mixes with random delays, sit in the recipient's mailbox and come back on the recipient's next fetch. On the devnet a first message to a new contact (Welcome, ratchet tree, then the text) typically arrives within 10 to 30 seconds.
